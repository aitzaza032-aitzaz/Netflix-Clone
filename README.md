# 🎬 Netflix Clone

A simple **Netflix Clone** created using **HTML and CSS** as a frontend practice project.

This project is a mini recreation of the Netflix landing page, focusing on layout, styling, responsive design, and visual presentation.

## 🚀 Live Demo

👉 [View Live Website](https://aitzazahmad.netlify.app/)

## 📌 Features

* Netflix-inspired landing page
* Responsive layout
* Navigation bar
* Hero section
* Feature sections
* FAQ section
* Email input section
* Footer
* Clean and simple UI

## 🛠️ Technologies Used

* HTML5
* CSS3

## 💻 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or backend is required.
